# 汉语拼音注音小助手 (Pinyin Annotator)

> 一键给中文文章加上汉语拼音，生成适合**幼儿园至小学低年级儿童**的注音读物。
> 纯前端 · 单文件 · 离线可用 · 文章内容永不上传
>
> 开源仓库：https://github.com/tjsky/pinyin-annotator · 作者博客：[秋风于渭水](https://www.tjsky.net)

## 为什么做这个

给家里孩子打印注音读物时，网上工具要么弹广告、要么需要把文章上传到服务器、要么多音字、的地得、儿化音错得离谱还不能改。这个小工具就是解决这些问题的：

- **内容不出本地**：所有拼音注音转换都在你的浏览器里完成，处理校内稿件、孩子姓名都没有隐私顾虑；
- **准确率第一梯队**：基于 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（官方自称测试准确率 99.846%），词组级多音字消歧（银行 / 行走 / 睡着了）；
- **错了能改**：点任意生字手动改读音，轻声（子 zi、地 de、着 zhe）、儿化音都能强制指定。

## 功能特性

### 注音引擎
- 教材式 ruby 上下注音排版，轻声自动不标调（妈妈 mā ma）
- 「一 / 不」变调开关：标实际读音（一个 yí gè）或标原调（yī gè），可选对齐教材习惯。
- 儿化音双模式：**逐字注音**（花儿 huā er，适合儿童指读认字）/ **标准拼音**（花儿 huār，符合汉语拼音方案对齐国标），女儿、儿童等真音节词自动豁免。
- **单字手动改读音**：点击生字弹出候选（含轻声/助词读音），改过的字标橙色。
- **单字儿化修正**：人名「润儿」「可儿」误判成儿化？点「儿」字一键强制儿化 / 非儿化。
- **易错点高亮**：底纹标出多音字、儿化音、的地得、一 / 不变调、常见轻声字，快速扫视检查
- **内置常用轻声词典**：豆子、椅子、高兴地、慢慢地等直接标对
- **拼音引擎内嵌离线可用**：同时支持联网同步上游更新（jsDelivr / npmmirror 双源）

### 排版与输出
- 汉字 16–48px 字号、楷体 / 宋体 / 黑体、拼音字体独立设置
- 字间距 / 行间距 / 段间距滑杆实时调节，解决长拼音黏连
- 翻页模式（300–1500 字/页）与连续滚动模式（2 万字上限），总上限 3 万字防浏览器卡死。
- **打印 / 导出 PDF**：A4 教材排版，页脚水印可勾选去除
- **三种复制格式**：富文本（粘贴进 Word 保留注音排版）、HTML ruby 标签、字「拼音」逐字对照
- **阅读模式**：隐藏编辑区，设备直接递给小朋友，方向键翻页

### 导入
- TXT 文件导入，自动识别 UTF-8 / GBK 编码

## 快速开始

- **在线使用：**[拼音注音小助手](https://tjsky.github.io/pinyin-annotator/) 
- **本地使用**：
  1. 下载本仓库的 `index.html`（单文件，约 360 KB）；
  2. 双击用浏览器打开——完成，你不需要安装任何东西；
  3. 粘贴文章 → 调整字号间距 → 打印 / 导出 PDF，或复制进 Word。

> 推荐使用 Chrome / Edge 等现代浏览器。全部功能在本地运行，无任何网络依赖（联网仅用于检查拼音引擎更新，你不点检查更新就完全不会联网）。

## 部署在线 Demo（GitHub Pages）

1. **Fork 或新建仓库**（仓库命名 `pinyin-annotator`保持不变，Public 可见）；
2. 把 `index.html` 放到仓库根目录（网页上传或 `git push` 均可）；
3. 打开仓库 **Settings → Pages → Build and deployment**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)**，点 Save；
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/pinyin-annotator/` 即可；
5. 以后更新：重新上传 `index.html` 覆盖即可，无需其他配置。

> 也可以放到任何支持html的静态空间（VPS、对象存储、Cloudflare Pages），单文件零后端。

## 隐私与安全说明

- 所有注音转换在浏览器本地完成，**文章内容不上传到任何服务器**；
- 「检查拼音引擎更新」仅向 jsDelivr / npmmirror 请求引擎版本号与代码，不涉及文章内容；
- 工具默认不收集任何个人信息，无统计、无广告。

## 准确性说明

拼音引擎准确率约 99.8%，但**不承诺 100% 正确**——多音字、轻声、儿化音、的地得在特定语境（尤其是人名、专名）下仍可能误判。工具因此提供：
- 易错点高亮，方便快速检查；
- 单字手动改读音、单字儿化修正。

给孩子正式使用前，建议开启「易错点高亮」快速过一遍。
